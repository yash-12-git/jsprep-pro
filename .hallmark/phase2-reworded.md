# Phase 2: lines changed on content pages

Removed, per the eyebrow rule (54): "JavaScript Interview Prep" and its React, TypeScript and System Design versions, "Predict the Output", "JavaScript "Wat?" Moments", "Free Resource", "Interview Preparation", "{label} Interview Blog", the "Level:" legend on topics pages, "Q1" over each category question (now "Question 1" under the title).

Rewordings follow one pattern: emoji removed, arrows removed from links and buttons, " — " became a comma or colon, " · " lists became separate items.
- "Practice Now — It's Free" -> "Practice now, it's free"
- "Start Free — 5 Questions" -> "Start free, 5 questions"; "View Pro — price/mo →" -> "View Pro, price/mo"
- "Read code → predict console.log → learn why." -> "Read code, predict console.log, learn why."
- Roadmap H1: "Frontend Developer Roadmap 2026 — 16 Weeks, 112 Days" -> colon instead of the dash
- Roadmap line: "JavaScript → React → Machine Coding → DSA → System Design" -> commas
- "2–3 hrs weekdays · 5–6 hrs weekends" -> "2 to 3 hrs weekdays", "5 to 6 hrs weekends"
- "Correct! 🎉" -> "Correct"; "Day N complete! 🎉" -> "Day N complete"
- Dashes in the FAQ and tip data of the question list pages became commas or colons. FAQ text feeds the FAQ JSON-LD, so that schema text changes by the same punctuation.
- Internal: "Not changed": page titles, meta descriptions, canonical paths.

Visual: per-post accent colours on blog chips and per-category emoji and colours were replaced by the shared chip styles.
